* Author: Rylee Hilde

## Overview

This program implements a simple shell that supports foreground, sequential, background, and pipeline commands

## Usage

To compile the program please navigate to the project directory and run the following command:

```make
make
```

To run the program run the following command:

```make
make run
```

To run tests change expected output of the command tested to what is run on your local machine and run

```make
make test
```

## Reflection

This project was quite difficult. I was unfortunately under a big time crunch with midterms and was not able to support pipelines in my shell as well as the rest of the builtin commands.

## Results

When running the shell you should be able to do the following "ad-hoc" testing to verify the functionality that does exist:

- simple foreground commands
- sequences of commands
- I/O redirection
- background commands
